# Job Portal – Full Stack Application



## Project Overview



The Job Portal is a full-stack web application designed to connect job seekers with recruiters. It provides a platform for job posting, job searching, applications, recruitment management, and administrative monitoring.



## Technology Stack



### Backend

- Java 21

- Spring Boot

- Spring Data JPA

- Hibernate

- Spring Security

- REST APIs

- MySQL 8.4



### Frontend

- React.js

- JavaScript

- HTML

- CSS



### Development and Testing Tools

- IntelliJ IDEA

- Visual Studio Code

- Git and GitHub

- Postman

- JUnit and Mockito



## Main Modules



1. User Management

2. Job Management

3. Application Management

4. Notification Management

5. Search and Recommendation

6. Admin Dashboard



## Project Structure



- `jobportal-backend/` – Spring Boot backend application.

- `jobportal-frontend/` – React frontend application.



## Project Status



Backend project setup and MySQL connectivity completed. Feature development is in progress.
